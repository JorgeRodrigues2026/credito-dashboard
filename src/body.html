O problema de negócio

Fila de análise manual não escala. Modelo preso em notebook também não.

Bancos, cooperativas e fintechs recebem milhares de pedidos de empréstimo. Decidir caso a caso gera espera e critérios diferentes entre analistas. O CreditAI coloca o modelo atrás de uma API que qualquer sistema consegue chamar.

Antes Análise manual

  • Cada pedido espera um analista disponível.
  • Dois analistas podem decidir diferente para o mesmo perfil.
  • Erros de cadastro só aparecem depois da decisão.
  • O modelo existe, mas só roda dentro do notebook do cientista de dados.
→

Depois CreditAI MLOps

  • Mesmo critério para todos: um pipeline treinado e versionado.
  • Resposta imediata via POST /predict, com probabilidade e faixa de risco.
  • Dados inválidos barrados na entrada (422) e incoerências de cadastro sinalizadas (400).
  • Analista no comando: o painel Streamlit mostra a decisão e o porquê dos números.
Fase 1 · Preparação do modelo

Um pipeline único, do dado cru ao arquivo .joblib

Pré-processamento e classificador ficam no mesmo objeto. A API recebe os campos do cliente como chegam e o pipeline cuida de imputar, padronizar e codificar.

1Base3.000 clientes, 8 variáveis, 43% aprovados
2Divisão70 / 15 / 15, estratificada antes de tudo
3Numéricasmediana + StandardScaler
4Categóricasmoda + OneHotEncoder
5Random Forest200 árvores, profundidade 10, classes balanceadas
6Artefatomodelo_emprestimo.joblib + métricas em JSON

Divisão sem vazamento de dados

A separação acontece antes de qualquer cálculo estatístico. Imputação e escala aprendem só com o treino.

Valores ausentes tratados

A base tem lacunas de propósito, como na vida real. O pipeline preenche sem descartar clientes.

Decisões técnicas

  • Mediana nas numéricas: resiste a rendas muito altas, que puxariam a média.
  • handle_unknown="ignore": uma categoria nova em produção não derruba a API.
  • class_weight="balanced": compensa os 57% de reprovados na base.
  • Artefato com metadados: versão, algoritmo e métricas de teste viajam junto com o modelo.
